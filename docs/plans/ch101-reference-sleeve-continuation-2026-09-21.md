## 실행 순서와 완료 기준

### 1. 상단 소매 재질 영역 분리 및 투영 얼룩 완화 — 즉시 실행

- 해시가 고정된 최신 작업본의 body 복사본을 만든다.
- 새 소매 위쪽의 전완 의상 영역을 손 로컬 좌표계·거리·연결성으로 제한한다.
  자동 선택은 **의상 영역 가설**이며 해부학적 분할로 승인하지 않는다.
- 진단 렌더로 마스크가 몸통·반대 팔·손·머리·허벅지를 침범하지 않는지 확인한다.
- 기존 이미지와 UV를 지우지 않고 해당 영역에만 별도 재질 마스크를 적용한다.
  상단은 점진적으로 원본 재질로 돌아가도록 한다.
- 원본 정점·면·UV·가중치와 선택 영역 밖 재질 표현을 보존한다.
- 정면·측면·후면 전후 렌더, 전체 정면, 영역 진단 이미지, report, Blend를 보관한다.
- 완료: 한정 영역의 재질 개선 실행과 보존·교차 검증 및 시각 검토.
  금색 선의 완전 연결·정확한 의상 패턴 복원은 이 단계 완료 조건에 포함하지 않는다.
  가림·회색 도색으로 문제를 숨겨 전체 품질 통과 처리하지 않는다.

### 2. 금색 트림 연속성과 소매 윤곽

- 승인 시트의 얇은 장식선과 현재 소매 상단의 연결점을 함께 확인한다.
- 단순 직선 연장이 디자인과 맞는지 검토하고, 선의 폭·방향·의상 경계를 작성한다.
- 각진 상단 개구부와 커프를 별도 복사본에서 제한적으로 보정한다.
- 정점 이동 상한, 새 교차, 비다양체, 면 방향, 실루엣을 검사한다.
- 완료: 여러 방향에서 경계·선이 납득 가능하고 정적 형상 검증을 유지한다.
  재질 shader는 추후 베이크할 때까지 Unity-ready가 아니다.

### 3. 나머지 CH101 실제 형상 개선

- 임시 손 재질·손가락·그립 변형, 반대 팔, 몸통 의상, 얼굴·헤어 순으로
  각각 별도 작업 단위를 정의한다. 부위별 전후 결과를 비교한다.
- 허벅지의 48-정점 스트립은 참조로 의미를 식별하기 전 삭제·자동 병합하지 않는다.
- 리깅 전에 각 부위의 실제 구조와 접합을 확정한다. 투영 이미지의 인식 가능성을
  실제 얼굴·의상 모델링 완료로 오인하지 않는다.

### 4. 기술 인테이크와 사람 Gate B

- 실제 모델의 컬렉션·UV·Material·LOD·Armature·Socket·Triangle budget 검증.
- 얼굴 BlendShape는 신뢰할 수 있는 제작·변형 증거 없이는 blocked 유지.
- 정면·측면·후면·3/4, 얼굴 확대, A-pose 및 기본 동작의 증거 확보.
- strict QA 기준을 낮추지 않는다. 이번 국소 재질 변경에 전체 점수를 임의 부여하지 않는다.
- 자동 기술 통과와 사람 Gate B 승인을 별도 기록한다.

### 5. CH102~CH105 → Unity → Android

- CH101의 기술 검증과 사람 승인 이후에만 캐릭터별 참조·계약을 적용하여 확장한다.
- 5개 승인 handoff와 mesh/package SHA256을 검증한다.
- Production validator, 사람 승인, 유효한 Unity Editor 환경이 모두 준비되어야
  Unity Import·Prefab·EditMode·PlayMode를 실행한다.
- Android Build Support 및 기기를 확보한 뒤 실기기 성능을 측정한다.
  필요한 환경·실제 모델·승인이 없으면 해당 단계는 Blocked이다.

## 실패·중단 조건

- source/art hash 불일치 또는 잠금 해제 입력: 수정·내보내기 중단.
- 국소 마스크가 다른 신체 부위까지 번지거나 참조 의상 경계를 입증하지 못함:
  마스크 범위를 수정하거나 진단 결과로만 보관. 승인하지 않는다.
- 새로운 교차·토폴로지 훼손·원본 변경: 산출물 채택 중단 및 원인 수정.
- 시각적으로 개선이 없으면 실패 원인과 필요한 구조 변경을 기록한다.
  같은 변경을 이름만 바꿔 반복하거나 점수를 조정하지 않는다.
