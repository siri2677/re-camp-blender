# CH101 equipment-only authoring study — NOT_PRODUCTION

Actual Blender meshes for one saber, one hollow-mouth sheath and one signal
ribbon. 972 triangles total, five materials, UV and authored part-endpoint
Sockets. This is not a full character or a selected Alpha Review candidate.

The ZIP preserves the initial UV-defective render and the corrected physical-
length UV revision. Start with `uv-fixed/three_quarter.png` and the `.blend`
in that folder. The old full-character artifacts remain in their own release.

Six real Blender regression tests and 132 Python tests pass; AI3D and Colab
package checks pass. These verify technical behavior, not final visual quality.
Guard/grip/clasp detail, reference-matched shading, character attachment,
body/face/hair/outfit, rig, LOD and physics are unfinished.

Gate B remains pending. Unity and Production remain disabled.
